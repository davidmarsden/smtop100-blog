# Theme snippets

Pieces of the Micro.blog theme that are edited in the Micro.blog UI
(Design → Edit Custom Themes), kept here so the canonical copy is reviewed and versioned.
The page-sync workflow does not publish these: paste them in by hand.

- `homepage-vacancies.html` / `.css` — homepage block on how to apply for a club, for
  current managers (rule 3.2, Manager Portal "Apply for a club") and new or returning
  managers (rule 3.3, the waiting list). The HTML goes in the homepage template straight
  after the hero section; the CSS goes in the theme's custom CSS.
