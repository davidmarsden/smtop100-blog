# Top 100 rule change log

This file records dated clarifications and substantive changes to current Top 100 rules so historical decisions can be checked against the rules that applied at the time.

## 13 September 2026 — Youth Cup fixture arrangements

The Youth Cup fixture-arrangement procedure was updated after changes to Soccer Manager made the old 24-hours-before-kick-off reminder obsolete for Saturday friendlies.

From 13 September 2026:

- Youth Cup fixtures are normally available by Sunday evening.
- The home manager must send the Soccer Manager friendly request promptly and no later than Wednesday.
- The away manager must check proactively and chase before Wednesday if the request has not arrived.
- Either manager should report a problem while there is still time for it to be resolved.
- Responsibility remains shared, but the duties are different: home initiates; away checks and chases.
- Evidence of a timely request, message or attempt to resolve the problem may distinguish an individual forfeit from a double failure.
- If neither manager makes a reasonable timely effort, both may be sanctioned; in a knockout round that can mean both are eliminated.
- Tournament reminders and newsfeed posts are a courtesy and do not replace managers' responsibility to find and arrange their fixture.

This clarification is prospective. It does not reopen S28 Youth Shield Round of 32 decisions made on 12 September 2026.
