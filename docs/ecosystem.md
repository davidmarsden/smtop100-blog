# Top 100 ecosystem map

This document records the role and intended future of each known Top 100 destination.

| Destination | Current role | Future | Notes |
| --- | --- | --- | --- |
| `smtop100.blog` | WordPress editorial/news site and historical archive | **Keep / redesign / later migrate to Micro.blog** | Main front door and publishing layer. |
| `archive.smtop100.blog` | Season, manager and historical statistics | **Keep / expand** | Canonical structured-history destination. |
| `youth-cup.smtop100.blog` | Youth Cup and tournament tooling | **Rename/evolve to `tournaments.smtop100.blog`** | Broaden beyond one competition; support multiple organisers and live tournaments. |
| `rules.smtop100.blog` | Rules and governance | **Keep** | Canonical reference destination. |
| `awards.smtop100.blog` | Manager Awards voting and history | **Keep** | Voting, Hall of Fame, cabinets and records. |
| `top100regen.website` | New sister game world, Top 100 Regen | **Bring under Top 100 umbrella; proposed `regen.smtop100.blog`** | Prefer one coherent family rather than a separate standalone identity. The exact technical migration/redirect plan should be worked out before moving the live site. |
| `legends.smtop100.blog` | Standalone historical/editorial concept | **Likely retire/absorb** | Preserve good material; move editorial stories to main site and structured facts to Archive. |
| `managers.smtop100.blog` | Standalone manager/community concept | **Likely retire/absorb** | Archive now provides a better long-term home for manager profiles/careers. |

## Desired user mental model

The permanent ecosystem should feel like one Top 100 family with a small number of clear destinations:

1. **Top 100** — what is happening and what the community is saying.
2. **Archive** — what happened, who did it and the statistical record.
3. **Tournaments** — competitions happening now and their histories.
4. **Awards** — recognition, voting and award history.
5. **Rules** — how the world is governed.
6. **Regen** — the sister Top 100 game world, visibly part of the same family but with its own game-world identity.

`Regen` is slightly different from Archive/Tournaments/Awards/Rules because it is not a specialist app for the main Top 100 world; it is a sister game world. It should therefore share branding, navigation and ownership cues while remaining clearly distinct from the original Top 100 competition.

## Top 120 precedent

`Top 120` is a useful historical precedent. It was Top 100's legacy sister game world and its material should remain in the archive. Top 100 Regen should avoid repeating the old pattern of becoming a disconnected sibling site. Bringing it under `regen.smtop100.blog` would make the relationship explicit from the start.

## Cross-site consistency to investigate

- shared global navigation;
- common logo/wordmark treatment;
- common typography and core layout conventions where sensible;
- consistent footer links and ownership language;
- shared social-card family;
- canonical links back to `smtop100.blog`;
- a clear Top 100 / Regen relationship;
- clear indication when a user is entering a specialist app rather than another blog page.

The goal is family resemblance, not forcing every app or sister world to use an identical UI.
