# What’s next for Top 100?

A lot of the recent work on Top 100 has looked like visible change: a new home, new navigation, new tournament pages, new voting, new manager accounts.

The more important change is underneath all of that.

We now have shared foundations that can be reused instead of rebuilding the same thing every time somebody has a good idea.

That makes the next phase much more interesting.

## More useful manager accounts

The manager account is already doing real work: fixtures, results, tournament progress, voting identity and Youth Cup reminders.

The visible manager-facing tool is **My Matches**, and that name captures the direction rather better than a generic portal ever did. Its job is to turn account data into clear actions: what am I playing, when, and what do I need to do?

The next step is not to turn it into a giant private website.

Public information should stay public.

The account should instead become the place for things that are genuinely personal or actionable: **my fixture, my ballot, my result, my reminder, my registration**.

That principle gives us plenty of room to grow without putting ordinary Top 100 content behind a login.

## World Club Cup reminders

Youth Cup reminders are the first live example of account-linked notifications.

Once that has had proper real-world use, the same approach can be extended to the World Club Cup rather than building another reminder system from scratch.

Registration deadlines are an obvious fit too.

The point is not to send managers more email. It is to send fewer, more relevant messages about things they are actually responsible for.

## Poll and Awards reminders

Community Polls and Manager Awards also have natural deadlines.

A manager account already knows whether somebody belongs to the relevant electorate, so future opt-in reminders could cover voting opening and closing without broadcasting every alert to everybody.

Again, world boundaries matter. Top 100 and Top 100 Regen should have separate electorates even when the underlying machinery is shared.

## My Top 100

The more ambitious idea is a proper manager career record.

We now have manager identity, Stats & History, tournaments and Awards moving towards the same underlying understanding of who a manager is.

That opens the door to a **My Top 100** view bringing together things such as:

- clubs managed;
- seasons;
- promotions and relegations;
- honours;
- tournament runs;
- Manager Awards;
- long-term records.

That is not a promise that the whole thing appears tomorrow.

It is an example of what becomes possible when the plumbing stops fighting us.

## More for Top 100 Regen

Top 100 Regen is already using the shared account and Tournament Manager foundations for Pane Trifunov's Season 4 Youth Cup.

From there, we can add more Regen features deliberately rather than simply copying everything from Top 100.

Separate Community Polls, separate Awards and other account-linked tools can all use the same foundations when there is a reason to build them.

## Better admin without robot government

There is also plenty of less glamorous work still to do.

Things like transfer bans, rules history, manager appointments and tournament administration can all benefit from better structured tools.

But there is a line we do not want to cross.

Software can check, calculate, record and recommend. Contentious decisions should still be confirmed by people.

The aim is less repetitive admin, not automated government by dropdown menu.

## Keep improving discovery

The rebuild is not finished just because the code works.

The recent Youth Cup changes are a good example. The data was already there, but managers still had to work too hard to find the fixture that mattered to them. Making **Schedule** prominent and turning the personal view into **YOU SEND / THEY SEND** was not new backend architecture; it was making the architecture understandable.

We still need to keep checking navigation, search, old inbound links, archives, categories, mobile layouts and the little inconsistencies that only show up once real people use the sites.

That work is not glamorous either, but it is what turns a collection of clever tools into one understandable Top 100 ecosystem.

## The direction of travel

The old Top 100 site grew organically over many years.

The new ecosystem will still grow organically — there is no stopping us there — but now it has stronger foundations underneath it.

One manager identity.

One public family of sites.

Separate game worlds where separation matters.

Shared tools where duplication does not.

And, ideally, fewer spreadsheets held together by memory and mild panic.

That is what comes next.
