## Product / architecture implications

- **All-Manager Polls:** still live and already marked APP. Current use is mainly agreeing rule changes; investigate a dedicated voting/poll function rather than relying on blog posts.
- **Job Applications:** APP + ARCHIVE + METADATA. The blog category is historical/organisational residue because the newer manager-application workflow supersedes it.
- **Transfer Bans:** LIVE + REVIEW. This is explicitly a painful recurring admin task and should be considered for structured management in an app rather than remaining post-driven.
- **Top 100 Rules:** remains LIVE. The redesigned main site should include a short prospective-manager summary explaining the relationship between Top 100 and Top 100 Regen, with clear links to the canonical Rules app and any Regen-specific differences.
- **Roll of Honour:** APP + ARCHIVE. Structured honours belong naturally in Archive while historical posts are preserved.
- **Top 100 News:** parent taxonomy only; marked METADATA + REVIEW. Review whether it is still useful as a visible category once Tournaments and the new homepage hierarchy are in place.
- **Club records:** preserve all club categories as reusable community infrastructure. Active records stay visible; dormant records remain revivable by future managers.
