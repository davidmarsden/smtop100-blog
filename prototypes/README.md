# Prototypes

This directory is reserved for design experiments that help define the future `smtop100.blog` without treating WordPress as the permanent implementation.

Likely prototype areas:

- homepage hierarchy;
- shared ecosystem navigation;
- article layout;
- historical archive landing pages;
- mobile navigation;
- social cards and branding;
- future Micro.blog theme components.

Prototype code should be portable where practical and should not assume access to WordPress features unavailable on the Personal plan.
