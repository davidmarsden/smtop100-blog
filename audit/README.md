# Audit outputs

This directory will hold generated inventories derived from the WordPress export and later checks of the live site.

Planned outputs include:

- `posts.csv`
- `pages.csv`
- `categories.csv`
- `tags.csv`
- `post-types.csv`
- `urls.csv`
- `redirects.csv`

These are working/audit artefacts, not the canonical backup. The full WordPress export and media download should be preserved separately.
