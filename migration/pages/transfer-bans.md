# Transfer Bans

Transfer bans are one of the sanctions used to enforce Top 100's squad and transfer rules.

The old WordPress page mixed the underlying sanctions with a long historical list of managers who had served bans. That list is useful as archive material, but it should not be treated as the current operational record.

For the current rules and sanction levels, use the canonical Rules site:

https://rules.smtop100.blog/

This page should remain as a short operational gateway until transfer-ban administration is moved into structured tooling.

## Current bans

Do not copy the old 2019 list forward. Current bans should either be maintained here from a verified source or, preferably, generated from the future admin workflow.
